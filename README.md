## Review status

The shared video shows the annotation work. Some boxes remain after vehicles leave, and those track endings need review. The original assignment rules are missing. This portfolio does not claim reviewer approval or an accuracy score.

The reading guide explains the saved export. It does not replace the original assignment rules.

Project method.pdf explains a working method inferred from the video and saved tracks. It identifies changing scale, image-edge exits, and lingering boxes. The original assignment rules and Joy's personal reasons are not reconstructed as facts.
